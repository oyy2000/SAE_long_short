# 固定878题的多答案蒸馏：完成报告

完成时间：2026-09-13 06:33:26 EDT。30个adapter、31组各1,269题的评估及最终审计均已完成。

**结论：本轮未确立增加同题正确答案数能扩大SAE相对无干预的准确率优势，也未确立不同答案优于重复最短答案。** 九项登记比较的95%区间均跨零，Holm校正p均为1.0000。这是不确定的比较结果，不代表两种方法等效或增加答案必然无效。

点估计上，两种方法在两条不同答案时均高于各自单答案结果，增加到四条后下降；不能据此推断稳定的最优答案数。SAE在1／2／4条时相对无干预分别少11.44%／12.33%／13.06%的学生输出token，长度缩短仍是描述性结果，不等于准确率改善。

## 数据与训练预算

保持原878道训练题。原候选池7,024条，53道题需要补生成；新增496条配对候选后共7,520条。两种条件下每题均有至少四条去重、正确、未触及生成上限的答案，无需删除题目。SAE和无干预各有22题的最短答案相对旧池发生变化，因此本轮重新训练单答案基线。

每题选最短1／2／4条不同正确文本；重复对照复制同一最短答案2／4次。两组各使用三个训练seed：17、42、73，共30个adapter。表中token为训练数据记录的completion token总数，每个seed使用相同数据。
