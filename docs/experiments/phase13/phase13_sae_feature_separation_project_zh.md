# Phase 13：长短推理 SAE 特征分离与可解释性项目

立项日期：2026-09-16。项目 ID：`phase13_sae_feature_separation_v1`。

本项目回应“long trace 和 short trace 应有清楚、可解释的 SAE feature 差异”的目标，作为 Phase 13 独立机制分支，与 B0–B7 学生效果比较并行管理。当前完成立项与历史证据梳理，尚未冻结新实验、训练新 SAE 或提交新作业。见[机器可读计划](../../../configs/phase13_sae_feature_separation_v1.json)和[历史消融回顾](phase13_sae_feature_evidence_review_20260916_zh.md)。

## 1. 研究问题与当前位置

核心问题：同一道题、同一个教师、都答对的长短推理，在排除答案格式、位置、题目难度及长度归一化影响后，是否仍存在效应足够大、跨题和跨 SAE seed 可重复、能指向具体推理行为的稀疏特征？

目前已有长短统计关联和教师长度干预结果，但还没有把“正文语义差异、跨 seed 稳定、特征特异因果控制”接成完整证据链。历史八个 short features 的整段差异很大，正文差异却接近零，不能直接命名为“简洁推理特征”。另一方面，Phase 5 曾找到 11 个清理后候选，值得恢复核验，不能概括为“从来没发现过差异”。

“明显”须同时包含效应大小、独立复现和可读案例。漂亮热图、二维投影、显著 p 值或生成变短，分别都不够。

```mermaid
flowchart LR
    A[证据与输入盘点] --> B[同题自然长短配对]
    B --> C[正文与格式分开评分]
    C --> D[语义反例与跨种子匹配]
    D --> E[未观察题确认]
    E --> F[双向因果干预]
    F --> G[独立学生实验]
```

| 独立终点 | 需要回答 | 当前状态 |
| --- | --- | --- |
| 表征差异 | 哪些 feature 在长短正文中稳定不同，对应什么行为？ | 有历史关联；正文语义与跨 seed 稳定性不足 |
| 因果机制 | 操作 feature 是否改变该行为，而不只是标题或结束倾向？ | 有长度控制；特征特异语义因果链未成立 |
| 蒸馏价值 | 新方向产生的监督是否改善 Qwen 3B？ | 旧方向单种子 pilot 已完成，未确立优于 B1 等基线 |

表征项目可交付可靠的阴性结果，不以学生涨点为完成条件；学生涨点也不能反向替代 feature 语义证据。

## 2. 首轮数据设计

优先使用现有 NCSU 可审计的 Qwen2.5-7B-Instruct 候选与激活开发方法。同题自然长短是主对比；官方短参考 vs 模型长输出、不同 prompt 或不同模型只作来源消融，避免把风格或模型差异称为纯长度差异。

先逐题合并历史 SAE 训练、discovery/dev/confirmation、学生训练和已观察评测的 ID、规范化题干及近重复组，登记观察用途。此前 132 题 held-out、300 题 confirmation、64 题消融和已观察 GSM8K locked test 均不能重新标记为未观察确认集。字典拟合、特征发现、调参与确认按问题组隔离，不默认还有足够新题。

开发规模目标为 128 道合格同题配对，仅用于可行性检查，不宣称已有确认功效。同提示、同答案格式、同解码和限定候选预算下，按正文 token 数对正确且去重的自然候选排序，取最短和最长，平局按 candidate ID 决定。没有两个合格候选、正文不足或 cap 截断的题按冻结规则剔除，保留完整池和排除原因；报告长度比，不临时提高长度比门槛挑效果大的题。

独立确认题数按开发数据的题间方差、最小有意义效应及多重比较预算确定，清单在任何确认评分前冻结。若 GSM8K 未观察支持不足，就记录不足；MATH 可另立迁移确认协议，不能静默换数据集或合并报效应。

## 3. 最小消融矩阵

先完成 F1–F3，再决定是否重训字典。一次改变登记的因素，避免同时换字典、输入、窗口和强度后归因。

| 编号 | 比较 | 控制与目的 |
| --- | --- | --- |
| F1 | whole / body / marker / suffix | 同字典、同轨迹，分离格式与正文 |
| F2 | 正文每 token 均值 / 固定支持 / 事件发生率 | 区分事件数量、强度及长度分母稀释 |
| F3 | 自然长短 / 统一最终答案格式的同文本变体 | 同题同教师，检验标题能解释多少关联 |
| F4 | 旧字典重新评分 / body-balanced 新字典 | 共用正文评价支持，区分评分与训练采样影响 |
| F5 | SAE seeds 17/42/73/101 | 固定输入、归一化和预算，按功能而非编号匹配 |
| F6 | 单 feature 正负 / 格式 / dense / 多随机对照 | 同状态与实际扰动范数，验证特异性 |

F2 主窗口拟设为最前 64 个合格正文 token，长短两侧均有完整支持才纳入该统计，同时报告完整正文及早/中/晚窗口。标题/后缀规则和 token/span 对齐在采集前验证；无标题时不能简单把最终答案计入正文。正文均值仍可能受事件密度影响，因此保留每题事件发生、每步频率和条件激活幅度。

固定早期窗口只定义观测范围。长 trace 后段的回看、验证等可进入另登记的全正文次要分析；不能为保留这些候选事后修改主窗口，也不能把 first64 无效当作所有后段特征无效。

新 SAE 起点沿用 layer17、TopK64、28,672 features、1,500 steps。body-balanced 的题目/trace/位置抽样、实际曝光、共用归一化及重构评价支持须冻结；暂不同时扫层与 k。正文重构不足时先登记质量诊断，再决定扩层或容量。

## 4. 让 feature 对应可理解的行为

初始标签只是待检验假设：重复叙述已知量、复算已完成的算术、尝试后放弃另一条路径、校验中间结果、直接合并运算、提取所需量。长不自动等于冗余，短不自动等于高质量；必要校验与无效重复要区分。证据不足的 feature 保留中性编号。

每个候选交付 feature card：checkpoint hash、层、seed、feature ID、入选规则、长短效应、覆盖率、区域激活质量、最高激活上下文、随机非最高激活上下文、无激活反例、同题长短、跨 seed 对应及失败例。图同时展示强度与激活比例，共用色阶，不逐行归一化制造分离。

格式反例保留计算正文，只替换/去掉标题；语义反例保留格式和最终答案，改变一个待检验行为，并核验数学正确性。改写导致的长度、位置、词汇变化须记录，不称严格只改变语义。对某个词响应不自动判为无用，但须检验含同词而无目标行为的反例。

解释在 discovery/dev 制定，保留上下文用于检验。登记标注者、是否看到方法/长短标签、分歧和覆盖率；项目助手解释不能冒充独立人工语义验证。

## 5. “明显且稳定”的拟定门槛

以下为立项默认设计，尚非冻结统计协议。最终样本量、检验族、匹配算法和读回容差须在确认数据开放前登记，不能看到确认结果后放宽。

- 统计单位为问题：先求同题长短差，再跨题汇总；token、候选、采样重复不是独立样本。报告原始激活差、paired d、覆盖率及问题级 bootstrap 区间，单列零方差和低覆盖。
- 探索发现：全字典 BH q<=0.05，正文 |paired d|>=0.5，题目激活覆盖率>=10%；每方向最多取 discovery 排名前 8 个候选，不补齐不足数量。
- 独立确认：同向，正文 |paired d|>=0.5，问题级 95% 区间不跨零，冻结候选族 Holm p<=0.05。0.5 是本项目拟定的有意义效应门槛，不是领域通用保证。
- 跨 seed：只用 discovery 的 decoder 和同正文状态激活冻结对应，确认时不重新挑最佳匹配。拟要求至少 3/4 seeds 同向且达到登记的效应门槛；报告全部失败和多对一拆分。cosine/correlation 0.5 只作辅助诊断，不单独证明语义一致。
- 语义解释：保留集有格式反例、同词异义反例及行为正反例证据。语义群稳定可另登记，但不能写成单 feature 稳定。

首个里程碑为至少一个满足完整要求的候选，理想展示目标为 3–5 个实例。双向都报告，不凑数量；只发现 long-associated feature 就如实报告，零候选也作为本版有效结论。

## 6. 因果与学生阶段

候选确认后，复用同前缀独立 KV cache 的读回，对比原状态、零操作、单 feature 正负操作，记录目标/非目标激活、TopK 替换、全词表 next-token KL、Answer/EOS 概率及实际范数。随机 feature 在 dev 同位置匹配覆盖率和幅度，确认时不换对照；吸取 Phase 5 对照覆盖率不足的教训。从不超过隐藏状态 5% 的局部扰动起步，无法达成目标控制则记录失败。

生成同时测预定义行为、正文长度、正确率、格式和 cap-hit。只缩短但行为未改变，不能写成语义机制成立。准确率非劣须另冻非劣界、样本量与检验，不能以 p>0.05 表示无损。

学生阶段再登记独立 B7 变体，与旧八特征 B7、B1、dense/format 等比较。复用现有 Qwen 3B 学生接口，固定共同题目支持与配方，分别报告等样本和等监督 token。token-KD、旧配方对齐各有自己的目标，不替代本项目的 feature 语义证据。

## 2026-09-16：Answer-free SAE 新执行分支

用户要求在 SAE 训练之前剔除 `Answer:` 标题及其后全部 token，重训字典、重新筛选特征，再依据特征读回和匹配随机对照决定是否进行教师生成。本分支 `phase13_answer_free_sae_v1` 是对上述 P1–P3 的独立实现起点，旧 NCSU SAE 和 Phase 5 产物不覆盖。旧 F24086 与旧八特征编号不能迁移到新字典；旧 Phase 5 的 11 个候选只作为历史动机。

新训练的输入复用已审计的 Qwen2.5-7B 第 17 层因果残差激活：每条轨迹要求唯一明确的 `Answer:` 或 `Final Answer:` 标题，丢弃标题 token 及其后全部位置、正文末 32 个原始 token、前 128 位置之外以及 Phase 5 登记的格式/纯标点 token；至少保留 64 个合格位置。同题长短两侧都满足才纳入。对 train/dev/test 各自按轨迹均衡配额抽取 250,000/50,000/50,000 个 token，固定 seed；重算训练归一化，不沿用旧 SAE normalizer。因为教师是因果模型，保留下来的标题前残差不依赖标题后的 token，可安全从已有 hash 核验激活中抽取；这不是直接重用旧训练样本。完整样本、位置和排除原因需审计，样本不足则停止。

新 SAE 沿用 layer17、TopK64、28,672 特征、1,500 步、seed17，训练/样本各写独立目录。后续先在已有 dev/test 题上做探索性固定 64 token 重筛选；确认时必须新题与问题组去污染，不能把旧 test 重命名为独立确认。读回与随机对照继续执行 Phase 5 的 5% 覆盖门槛、目标相对变化和非目标变化限制；不过门槛不进入生成。生成前另冻新题、对照和统计协议。

已提交准备 853536、CPU 样本 853537（afterok）、H200 SAE 训练 853538（afterok）。实际 Slurm batch 与指定 scratch 启动器逐字节核验。此处仅为提交，尚无训练完成或新特征结论。见[执行配置](../../../configs/phase13_answer_free_sae_v1.json)与[提交核验](../../../results/phase13_sae_feature_separation_v1/exploratory/answer_free_sae_v1/verification/batch_audit.json)。

### 执行修订与当前状态

v1 准备逻辑错误地要求同题标签集合恰好为 `{short,long}`；原语料同题还包括 `other_correct`、`medium`、`incorrect`。853536 因此失败，853537/853538 依赖取消，均无有效 SAE 产物，历史快照保存。v2 只要求同题同时有 short/long，并只保留这两类轨迹进入样本；三项回归测试通过。v2 的准备 853543、CPU 采样 853544、H200 训练 853545 与筛选冻结 853652 均完成。109 个原激活 chunk 核验后登记 train/dev/test 250,000/50,000/50,000 token；新 TopK64 SAE 完成 1,500 步，训练完成标记的 6 项文件哈希通过，最后 dev MSE 0.2264、解释方差 0.7733。四个评分分片 853657–853660 与分析 853661 均完成；2,030 条轨迹和 129,920 个固定正文 token 零缺失/重复。16 个注册候选中 4 个通过清理后筛选，按 dev 排名选出新字典 F20319（dev 原始/校正 d=0.606/0.460，旧 test 原始/校正 d=0.559/0.390）；这是已观察题池内的探索性复现，不是独立确认。

同状态读回另冻 `screen/engagement_launch_v1`，只用 dev 四个实际读回位置匹配两个随机特征，要求随机对照 dev 激活覆盖至少 5%，沿用 Phase 5 的 5% 隐藏状态范数上限、25% 目标读回变化及非目标/目标 L2≤2 门槛。853699 冻结、853700–853702 双向 GPU 读回、853703 CPU 审计均完成；实际五份 batch 均核验指定 scratch。审计 24,240 条逐状态记录，零缺失或重复。预定主特征 F20319 在 dev 读回位置覆盖仅 2.94%，在 test 读回位置覆盖 2.40% < 5%；正负目标变化为 −63.13%/+56.81%，非目标/目标 L2 为 1.079/1.206，但整体未过门槛。随机特征 7540 和 8589 各自的双向读回指标通过；8589 的 dev 覆盖为主特征 2.44 倍，超过登记的两倍匹配范围，因此对照匹配也失败。最终记录 `stop_target_or_control_engagement_failed`；教师生成与学生训练未触发，不能据此声称特征具有生成长度因果效应。

本次冻结匹配代码只要求对照 dev 覆盖≥5%，未在冻结前核对主特征覆盖，也未在随机抽取前严格过滤两倍比率，造成可预见的失败。历史快照与失败产物保留。若另立新协议，须在 dev 实际读回位置先约束主特征覆盖和随机对照两倍频率/幅度，再冻结主特征及新题；旧 test 已观察，不能复用作独立确认。`support_audit.json` 中的 `unpaired_after_cleaning` 包含原先非 short/long 标签，不能解释为丢失的长短成对数；准确分类见 `verification/support_audit_interpretation.json`。这一修订未改变截断、采样或训练参数。
