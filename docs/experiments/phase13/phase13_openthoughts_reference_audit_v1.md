# Phase 13：OpenThoughts 参考解析、跨源一致性及内部近似题

本阶段接续已完成的 [来源审计](phase13_openthoughts_inventory_v1.md)，检查全部 64,946 个预筛候选，仍不构成 25K 训练题池。使用 `configs/phase13_openthoughts_reference_audit_v1.json`、复用模块 `openthoughts_reference_audit.py` 和入口 `13_45_audit_openthoughts_references.py`。

准备阶段重新验证 12 个原 metadata 文件及来源结果、完整性复核和 MATH cohort 绑定，固定 64,946 个候选 ID、原参考 box、四个交错分片及全部 89,120 个数学问题。只以当前 MATH `student_pool` 中精确规范化同题的参考作为跨源对照，校准/开发/评测答案不参与该对照。

参考解析复用既有 `compile_answer_spec` 和 `grade_typed_response`，保持进制、元组次序、区间边界、选择字母、多答案重数及超时规则。对每个来源答案报告两个不同结果：

- 将原参考 box 与其自身比较，用于发现解析和格式缺口。通过不证明原解答正确、完整或足以回答问题。
- 有精确同题 MATH 参考时，以原 OpenThoughts box 作为待判答案、MATH 参考作为 gold，报告跨源一致性；不一致和解析失败都进入复核，不静默替换来源答案。

内部近似检查复用原 5-gram Jaccard ≥ 0.8 匹配与 `math_cohort_freeze.components`。在全部 89,120 个数学问题上计算连通组，包含证明题、直接匹配保留题和其他非候选问题。任一组含直接保留集匹配时，整个组均隔离，防止经非候选桥接题间接泄漏。近似连通并不证明组内问题语义相同；这是保守隔离规则，不是自动同题标注。

最终合并必须等待四个解析分片及完整近似审计，检查逐分片题序、唯一性、输入行哈希和总数。输出解析/跨源一致性复核案例、暂可解析的候选 ID 与 near 组，以及按事先固定 seed `2026091325` 选择的 32 个来源质量样本。该样本选择不依赖审计结果，仅用于后续阅读原问题和参考解答，不是模型开发集或独立人工标注。

科学与依赖版本在启动前冻结。当前 grader 为 `phase13_typed_math_grading_v2`，使用 math-verify 0.9.0、latex2sympy2_extended 1.11.0、antlr4-python3-runtime 4.13.2、SymPy 1.14.0。历史评分与已冻结训练/生成代码不修改。新测试覆盖“错误参考自比较通过但与 MATH 不一致”、等价参考、禁止生成答案回填和经非候选节点传播保留集隔离；与原 12 项评分回归共 16 项。

冻结目录为 `preparation/openthoughts_reference_audit_launch_v1`，401 项绑定。测试 `823972` 和准备 `823973` 已 COMPLETED / 0:0；四个解析作业 `823974`–`823977` 及内部近似检查 `823978` 已实际运行，合并 `823979` 等待全部成功。均为 NCSU CPU 作业，当前指定已检查的 `c026n04`；四个解析作业各 1 CPU/6G，近似检查 2 CPU/16G，合计最多 40G 请求，受调度器实际容量约束。没有 GPU 生成、学生训练或 25K 选题。

完成后仍需解释复核案例、阅读来源质量样本并验证参考/题型语义；随后才可按原 S4 结果及成本检查推进 S5。解析通过和跨源参考一致都不能替代教师正确覆盖、八方法共同支持或正式学生结果。

## 已执行结果与主流程影响

四个解析分片、内部 near `823978` 和合并 `823979` 均 COMPLETED / 0:0。near 用时 19 分 17 秒，合并 9 秒；等待期间检查到真实 CPU 时间持续增长，未因较长运行时间重启。准备的 14 项、四分片各 5 项、near 的 6 项和合并的 12 项直接绑定复核通过。

64,946 个候选中 63,231 个自比较通过，1,728 个解析/一致性复核 case。5,494 个精确 MATH 对照中 5,478 个一致。全体 89,120 个数学问题形成 88,968 个 near 连通组，157 对边、最大组 3 题；原直接保留的 690 题没有新增传递邻居。按当前 v2 评分，暂可解析且未连接到保留题的候选为 63,218 个，覆盖 63,121 个 near 组。32 个来源质量样本已生成，后续完整阅读已完成，见下节。

这些数量不证明原参考正确。16 个跨源不一致的复读反而揭示 MATH 最后一个 box 丢失多答案等问题：部分 gold 必须修订，框外负号例也是提取损失，而非原解答算错。当前主文本入口已 hold，后续优先完成 [参考完整性修订](phase13_math_reference_integrity_v1.md)，保留本次 v2 解析结果为诊断证据，不把 63,218 直接变成训练题池。

## 32 个来源质量样本完整审阅

已完整阅读预先抽定的全部 32 个问题与参考解答，逐题记录在 [来源质量审阅](../../../results/phase13_baseline_expansion_v1/preparation/openthoughts_source_quality_review_v1/reviews.jsonl)，由项目助手完成，不是独立人工证明标注。源样本、原问题/参考、原 source-fields 哈希、canonical 建议与理由均绑定；原 gold 和候选池修改数均为零。[完成标记](../../../results/phase13_baseline_expansion_v1/preparation/openthoughts_source_quality_review_v1/COMPLETE.json) 的六项直接绑定通过。

其中 10 个案例的最终答案可支持，但参考推导有明显错误或不完整排除：错误代数、错误前提复述、仅检验一个值后断言全部无解、未证明极值等。另有四个题意/操作数 caveat：没有班级人数却要求选学生队伍、年龄倍数译文、26 个数却要求 26 次二元合并，以及“不同乘积”与“不同数对”的区别。还有全零序列使分式未定义的通常定义域限制及省略的三角恒等式等，均单独说明。

对有限案例另做了明确范围的精确检查：枚举全部 59,049 个非零五位数字串，七个格点，初始花生数 1–25，以及 1.999 的有理数幂阈值。检查支持相应最终答案，不认证其他参考全文。32 个样本均来自 metadata 的 `source:numina_math`，不能据此给其他来源或整个题池估计错误率。

下一步在后续 25K 准入中保留题意隔离、显式题型和参考来源规则；不能以自比较通过直接接纳含歧义的问题，也不能把这些参考推导自动作为有效蒸馏监督。扩大到 S5 仍需先完成当前 S4 学生比较与成本判断。本次审阅不将暂可解析的 63,218 个 ID 改称已验证训练池。
