# Phase 13：保留题 SAE 干预确认

配置 `configs/phase13_sae_confirmation_generation_v1.json` 与 `configs/phase13_sae_confirmation_analysis_v1.json` 使用原来保留的 300 道 GSM8K train confirmation 问题。复用 `sae_generation_controls` 的真实逐 token 解码、范数匹配 hook、区域划分、窗口检查及审计，扩展其显式问题角色选择；未创建另一套生成实现。

这些题的未干预输出已在最初 1,000 题 baseline 中生成并统一评分。它们没有进入方向拟合、dev 剂量选择和干预效果分析。因此，本阶段的独立性限于保留题的新干预效果，不称为从未观察过的问题或全流程盲测。

## 冻结设置

沿用最初 mechanism 输入的 `rho_reference=0.3`。不根据后来的 MATH 学生源选点改用 rho=0.2。300 题各生成未干预、历史八 SAE features、dense、answer-format 和三个随机 SAE 方向，共七条件、2,100 条。另按原哈希规则从这 300 题固定抽取 64 题，完整复验 24 个特征数/单特征/leave-one-out/时间窗口条件，共 1,536 条。

教师、SAE 权重与特征、dense/format 方向、随机集合、采样 seed、1K cap、batch size 8、四分片、rho、窗口边界及 smoke 条件均须与已完成 dev 协议一致。只改变问题角色和预先明确的剂量网格收缩。八题 smoke 仍取原独立 smoke 集，共 88 条，不占用 confirmation 问题。原 dev 和旧 baseline 产物保留。

配置在生成前包含完整确认分析计划，解析器要求其与最终分析配置完全相同。确认协议还绑定 dev 协议、源码和已完成 dev 分析。任何改变方向、剂量、生成参数或问题角色的尝试都会失败。

## 统计与解释

主要比较为 SAE 对未干预及五个其他方向，分别比较最终答案正确率、实际生成 token 数和重分词后的 reasoning-body token 数，共 18 项双侧检验，作为同一个 Holm 校正族，alpha=0.05。准确率使用 exact McNemar；长度使用题内方法标签可交换零假设下的符号随机化，最多 16 个非零配对穷举，否则固定 seed 的 20,000 次 Monte Carlo，并使用 plus-one 修正。

配对 bootstrap 区间是边际描述，不是同时置信区间；不将 bootstrap 尾部比例当作精确 p 值。64 题的特征/窗口消融和 marker/suffix 指标属于次要描述。完整输出需要另外执行相同的逐文本答案复核，旧题号或旧评分不得替代新文本审计。

本阶段只使用一个历史 SAE、一个固定采样随机流。无论结果是否有利，都不能替代另外三个 SAE seeds、学生 SFT 或基线之间的准确率—成本比较；未拒绝差异零假设也不能证明非劣。生成计时含 SAE 读回和标题检测开销。

## 确认结果

| 条件 | 正确数 / 300 | 生成 tokens | 正文 tokens（重分词） |
| --- | ---: | ---: | ---: |
| Unmodified | 287 | 290.60 | 282.33 |
| SAE，rho=0.3 | 279 | 249.95 | 242.93 |
| Dense，rho=0.3 | 276 | 204.90 | 198.84 |
| Answer-format，rho=0.3 | 277 | 246.47 | 240.17 |
| Random SAE 1 | 287 | 291.28 | 280.95 |
| Random SAE 2 | 285 | 302.09 | 293.95 |
| Random SAE 3 | 286 | 298.73 | 291.36 |

七条件均零 cap hit。SAE 相较未干预少 40.65 个实际生成 tokens、少 39.39 个正文 tokens；相较未干预及三个随机方向的总长度和正文长度检验均通过同一 18 项 Holm 校正（adjusted p=0.000900）。因此缩短不只发生于答案后缀。

SAE 相较 Answer-format 反而平均多 3.48 个生成 tokens，两项长度与准确率差异均未通过校正，未确立 SAE 独有优势。SAE 相较未干预的正确率数值下降 2.67 pp，McNemar 原始 p=0.0963、Holm p=0.6738；这不能解释为准确率非劣。Dense 更短，但观察正确率更低。完整消融为次要描述，不能按其最高点追认新确认策略。
