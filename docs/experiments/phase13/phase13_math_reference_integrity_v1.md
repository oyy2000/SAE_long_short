# Phase 13：MATH 参考完整性修订与下游暂停

OpenThoughts 与 MATH 的精确同题交叉核对发现，原 `extract_boxed` 只读最后一个 box，无法完整表达某些多答案、任一可选答案或框外语义标记。这不是通过来源答案自比较就能发现的问题。原始生成轨迹、旧评分和已冻结代码保留；主实验正式学生比较尚未开始。

## 已确认的发现

四个 OpenThoughts 参考检查分片 `823974`–`823977` 全部 COMPLETED / 0:0，检查 64,946 个候选；63,231 个自比较通过，1,728 个解析或跨源一致性 case 需要复核。精确匹配的 5,494 个 MATH 参考中，5,478 个通过当前评分器的交叉比较。16 个不一致案例已逐项记录为提取或上下文问题，不能当作 16 道原始参考解答错误。

例如，方程因式题要求 `-5/2` 和 `1/3`，两个来源都有完整推导，但 box 顺序不同，最后一个 box 因而产生不同、不完整的参考；三角形题丢失了 30 度，只保留两个 75 度；相切圆题要求 1、9，却只保留 9。另一例原 OpenThoughts 解答为 `-\boxed{15}`，数学解答正确，提取时丢失了框外负号。不要延续“原参考算错了正负号”的解释。

其他已读案例包括请求百分数时的百分号位置、百分比等价链、分数中的千位分隔符、文字 four、框外 base-5 下标、带完整标签的选项和文字连接的答案列表。修订要利用题目上下文并保留多答案重数、顺序和可选关系；不能全局允许任意 100 倍答案，也不能自动拼接所有中间 box。

完整筛查入口 `13_46_scan_math_references.py`、模块 `math_reference_integrity.py` 和配置 `phase13_math_reference_integrity_scan_v1.json` 已冻结。三项嵌套/转义 box、双答案和进制上下文检查及 CPU 扫描 `824110` 均通过，扫描现有 7,487 个 MATH 训练各角色问题及 500 个 MATH-500 问题，共 7,987 题。

启动的 400 项、扫描结果的 11 项、hold 记录的 2 项及两份语义复核各 6 项直接绑定已经验证。单独检查全部扫描来源中的紧邻 box 负号，唯一命中是 `math_train-03563` 的减法和 phantom 占位 box，已落入多 box 复核；没有据此给该题自动添加负号。

629 个案例被标记：多个 reference box 122、多个答案请求 257、百分比上下文 63、文字参考 148、进制上下文但未标记 radix 65、无 reference box 2；标记可重叠，也有正常题。所有原问题、参考解答和已登记 gold 均保留，没有自动修订或删除训练题。
