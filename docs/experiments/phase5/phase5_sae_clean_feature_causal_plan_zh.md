# Phase 5：去除长度与格式混淆后的 SAE 因果验证

## 目标与边界

检验在排除答案格式、末段位置及按整段长度归一化的影响后，是否存在可重复的早期长短关联特征；进一步检验改变该特征能否改变教师输出长度。沿用 Qwen2.5-7B-Instruct、第 17 层和已有 full_trace_balanced SAE。旧 Phase 2/3 产物不覆盖。本轮为探索性检验，不声称推理机制或学生效用。

设置在 `configs/phase5_sae_clean_feature_causal_v1.json`，冻结协议及新产物位于独立的 `results/phase5_sae_clean_feature_causal_v1/exploratory`，大文件存储在 BeeGFS。优先运行可否决假设的检验，后续步骤按预设门槛触发。

## A. 固定支持集的特征重筛选：本轮首先执行

1. 复用旧候选池作探索性重分析，沿用原 dev 发现集和 test 确认集，明确它们已经用于先前分析，不称为新的独立证据。
2. 排除 `Answer:` 答案段、最后 32 个原始 token、纯空白/标点和配置中列出的格式/LaTeX token。
3. 每条轨迹从前 128 个原始位置中取恰好 64 个合格 token，前 32 个作为早期复核窗口；不足 64 个的轨迹剔除，并只保留长短组均存在的题目。
4. 复用哈希验证过的原始残差激活，以三个互斥分片并行编码全部 28,672 个特征。固定 64-token 分母，按题汇总长短差异；不得再除以整段回答长度。
5. 在 dev 拟合数字占比、平均原始位置、窗口跨度三个协变量的线性校正，再将固定系数应用于确认集；原始与校正后的关联均须保留。
6. dev 使用 BH q≤0.05、|paired d|≥0.2、激活覆盖率≥5%；每方向最多八个候选。确认集使用候选集合 Holm p≤0.05、|paired d|≥0.15、同向早期关联 p≤0.05。单个 token 的激活质量占比不得超过 30%。
7. 记录旧四个短特征作为格式伪相关的负面参照。若零特征通过，完成本轮阴性检验，停止后续因果与学生训练；不得放宽门槛补选特征。

## B. 目标激活读回：仅 A 通过后执行

每次只操作一个通过筛选的特征，按冻结的 dev 排名确定主特征，避免重新挑选确认集最优者。在确认集的固定残差位置使用激活门控的对称操作 Δh=α z_f d_f/scale，α∈{-1,+1}，扰动范数不超过原隐藏状态的 5%。以 FP32 重新编码干预前后完整 TopK，记录目标激活、TopK 成员变化、非目标变化以及截断情况。

操作需至少覆盖 5% 的测试状态，目标激活改变方向正确且平均相对改变≥25%，非目标激活变化范数与目标变化范数之比≤2。使用两个固定随机种子选择激活频率及幅度接近的随机特征，同样门控、同样限制扰动。未达到门槛则记录未实现特征特异控制，不进入生成。

## C. 独立题目上的双向教师生成：仅 B 通过后执行

从 GSM8K train 中排除所有旧 corpus 题目，固定选择 64 道新题，每题两个采样重复。每题运行无干预、主特征正负方向、两个匹配随机特征的正负方向；分别从第一个输出 token 和共同前缀 64 tokens 后开始，共 1,792 条输出。

复用并检查已有 cache-clone 工具，每个分支复制同一个缓存；第一个待生成 token 必须真正受到干预。每进程一张显存足够的 GPU、每次一条序列，避免 padding/EOS 后诊断污染。记录逐有效 token 的目标读回、扰动强度、结束原因、完整输出与正确率。

主检验为相对无干预至少缩短 5%、配对区间支持缩短且优于同强度匹配随机方向。按题 bootstrap、对条件比较作 Holm 校正；正确率下降的区间上界须支持不超过 5 个百分点。正负方向响应与起始位置作为机制复核，不能仅凭单个成功条件作机制结论。

## D. 学生蒸馏：本轮不默认触发

只有 C 同时显示教师端定向长度效果和可接受的正确率损失，才制定独立数据生成与学生训练协议。若 A/B/C 任一预设门槛失败，本轮以明确的阴性结论结束，不启动学生矩阵。

## 验证与产物

对 token 对齐、固定支持数、分片重复/缺失、配对统计、协变量校正和干预读回进行必要测试。每个阶段保存配置/输入/代码哈希及完成标记。结果优先以原始与清理后效应对比图、特征筛选流程图和双向干预曲线呈现；未运行阶段明确标注为未触发。

## 本轮执行状态与注册修订

A 已完成：2,047 条轨迹、131,008 个固定支持 token、28,672 个特征；11 个候选通过确认，主特征为 24086。

B 已执行两版并完成逐状态审计。v1 对照 882 的确认集覆盖率为 1%，未通过。v2 保留失败产物，仅用 dev 的实际读回位置重新匹配随机特征并预筛 dev 覆盖率≥5%，未改变确认门槛；冻结文件为 `engagement_protocol_v2/protocol.json`。主特征双向操作通过，v2 对照 3739 的确认集覆盖率为 4.15%，仍未达到 5%。按门槛结束本轮，不继续换对照或放宽阈值。

C、D 未触发，也不计作已实施的生成或训练。后续若启动新协议，应先解决同位置、同扰动量的随机对照，再冻结独立新题；不得将本轮已看过的确认结果重新包装为独立确认。
