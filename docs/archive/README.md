# 文档整理归档

本目录保存 2026-09-16 整理前的 Markdown 原文，便于核验历史文档哈希及查询旧路径。它不新增实验完成证据，也不替代原实验的结果与审计文件。

- [原文 ZIP](docs_before_reorganization_20260916.zip)：整理前 `docs/` 下的 Markdown 文件，ZIP 内保留原仓库相对路径。
- [路径与哈希映射](doc_path_migration_20260916.json)：迁移文件和受影响引用文件的旧路径、新路径及整理前后 SHA-256；`original_in_archive` 标明是否保存了对应 Markdown 原文。

日常阅读使用 [文档索引](../README.md) 中的新路径。旧审计记录仍保留其原始路径和哈希：核验历史 Markdown 时，按 `old_path` 从 ZIP 中读取原文字节并与历史 SHA-256 比较；查找当前位置时使用 `new_path`。根目录说明文件和 Python 文件只记录变更前后的哈希，不包含在原文 ZIP 中。

论文 ZIP、扩写版源码及其构建记录未改写；它们的迁移记录也包含在映射中。部分历史链接原本就指向当前工作区没有的旧集群产物，目录整理不表示这些产物已恢复。原位置不保留软链接，避免混淆归档原文与已更新链接的阅读版。
