# Baseline 与 SAE 分析补充方案

日期：2026-09-13。本文是研究设计建议，不是冻结协议，也不代表已提交或完成任何新实验。范围保持 GSM8K，既有探索性结果及冻结配置不变。

## 当前证据决定的优先级

本轮 NCSU 干预使教师和无干预蒸馏学生的输出缩短，但未确立学生准确率收益。当前八个 short-associated 特征的最高激活上下文均集中在 `Answer` 附近。例：F7339 在短、长组的 `Answer` token 关联值约为 12.0/12.2，F17885 约为 9.98/10.3。这是答案格式关联的线索，不是该词解释全部激活或干预效应的证明。

若一个答案标记每条轨迹仅出现一次，且每次激活约为 A，则整条轨迹平均激活可近似为 A/L。因此按 token 归一化仍可能产生机械的长度关联。现有 first64 同向检查不能单独排除这个解释，需要区分前64 token中答案尚未出现和已经出现的轨迹。

证据来源：[token contexts](../../results/ncsu_phase12_reproduction_v1/exploratory/sae_features/analysis/token_contexts.md)、[当前干预报告](../experiments/phase12/ncsu_sae_intervention_status_20260912.md)。

研究应依次回答：简单控制能否替代 SAE；SAE 改变了哪些文本内容；这种变化是否有学生价值。

## 比较矩阵

| 优先级 | 条件 | 实施原则 | 可回答的问题 |
| --- | --- | --- | --- |
| P0 | Base student | 本轮同环境评估；不混用历史 base | 本轮蒸馏的起点 |
| P0 | Random-correct / shortest-correct | 同一无干预候选池、相同问题；随机正确采样预先固定种子 | 短轨迹选择相对普通正确采样的作用 |
| P0 | Concise prompt | 要求完整且简洁解答，保留统一答案格式；开发集固定提示 | 简单提示是否足够 |
| P0 | Dense short–long direction | 同题正确样本、相同层、每题等权；在开发集校准强度 | 是否需要 SAE 分解 |
| P0 | Answer-format direction | 逻辑步骤相同、仅答案标记不同的配对模板，控制绝对位置；方向学习与测试题分离 | 当前效应是否由答案格式或答案段转换方向解释 |
| P0 | Matched random SAE sets | 匹配特征数量和实际扰动范数；预先抽取多个独立集合，报告全部 | 特定集合是否优于一般方向扰动 |
| P1 | ASC | 明确正式版 CES 与 KL 约束；先核对实现对 Qwen2.5 Instruct 的适配 | 能否超过最近的内部压缩方法 |
| P1 | DAP / post-hoc compression | 普通改写与完整 LiteCoT 难度感知流程分别命名；计入改写模型成本 | 内部干预与文本压缩的差别 |
| P2 | Mixed short/long | 固定总样本与问题曝光，提前固定混合比例 | 混合复杂度是否优于纯短监督 |

当前 no-steering 蒸馏已经使用四候选 shortest-correct，因此新研究不能把它改名为 random-correct。现有 natural-short 来自16候选下20%长度带代表，属于另一种数据构建策略；需要重新构建同池选择对照，而不是将旧结果当成选样规则已匹配。

主表建议保留 Base、Random-correct、Shortest-correct、Concise prompt、Dense、ASC、Compression、Ours。随机 SAE 和答案格式方向主要用于机制消融；若格式方向可以解释主要效果，则应进入主文核心比较。

ASC 来源：[Activation Steering for Chain-of-Thought Compression](https://aclanthology.org/2026.findings-acl.1828/)。DAP 来源：[Concise Reasoning, Big Gains](https://arxiv.org/abs/2505.19716)。正式版 ASC 不等于简单均值差方向，普通缩写也不等于完整 LiteCoT 复现。

## 公平性与成本

1. 固定教师、学生、问题、候选数、验证规则和选样规则。提示方法可以改变提示，其余生成设置统一；有意不同的参考数据或额外模型调用单独登记。
2. 生成端报告所有输出的正确率、cap-hit、长度、覆盖率及每百万生成 token 的可用正确轨迹数。训练端在共同支持集比较，同时报告被排除题目，避免共同交集掩盖某方法失败。
3. 等样本为主比较，等监督 token 单独报告；完整轨迹重复不能称为等优化步数或等题目权重。若要研究预算原因，另做固定步数/固定目标 token 更新预算的登记实验。
4. 生成预算做两种视角：同候选数用于控制选样机会；同总生成 token 用于研究端到端实用性。这两者不能同时天然相等。
5. 强度在开发集校准，报告准确率—长度曲线与固定压缩水平的比较；同 hidden-norm 比例不代表同输出 KL 或同样的行为干扰。
6. 长度匹配优先使用开发集调到相近长度的条件，并辅以同题候选匹配。明确共同支持、匹配容差、残余差异和覆盖率。后处理匹配只能提供条件性比较，不能单凭匹配后差异证明内容的因果中介作用。
7. SAE 拟合、激活提取、方向学习、额外改写调用与在线干预时间均计入成本；报告复用已有字典后的边际成本及新训练字典的总成本。
8. 对新方法的开发选择使用 GSM8K train 中与旧发现集分离的问题，保留现有锁定评估规则。已观察的测试集不能恢复为未触碰确认集；新结果继续明确探索性范围。

## SAE 分析 A：答案格式与长度分母效应（P0）

- 计算每个特征在 `Answer`、标点、正文、末尾窗口中的激活质量占比，不仅列 top contexts。
- 分别报告整条均值、正文均值、答案段均值、每次答案标记出现时的激活及词出现次数。
- 把平均激活对 1/L 的关系与剔除答案区域后的同题效应并列；整条激活总量只能作为诊断，不作为新的未控制长度主统计量。
- 用绝对位置、相同 token 身份、正文窗口内等量采样控制位置与词频；比较相同语义步骤对应的窗口。
- first32/first64 的在线预测只对在该时点仍在生成的轨迹定义，记录提前结束比例；以已经出现的前缀信息预测剩余长度或未来答案段进入时间，禁止使用由未来总长度定义的相对位置特征。
- 离线剔除末尾窗口可做事后诊断，但不能称为在线预测，也不能用其未来信息构造实时控制器。

## SAE 分析 B：语义反证（P0）

选取新的 GSM8K train 解答，构造逻辑不变的措辞/格式变体，同时在非推理文本中插入 `Answer`、`Therefore` 或对应 top tokens。检验格式替换后激活、逻辑保留率与 token 对齐。

至少包括逻辑步骤相同但答案标题不同、格式相同但计算错误、非推理文本插入答案标题三类。人工或规则核对计算步骤与最终答案。删除词会改变后续位置和表示，需要保留原文—改写文对齐，不能仅比较全序列均值。

上述设计回应 [Do Sparse Autoencoders Identify Reasoning Features in Language Models?](https://arxiv.org/abs/2601.05679) 的反证问题。反证失败说明语义解释不成立，不等于这个方向完全没有工程用途。

建议图：真实解答、等义改写、格式替换、非推理注入的激活矩阵。

## SAE 分析 C：干预是否改变目标特征（P0）

在同一批固定 hidden states 上比较 Enc(h) 与 Enc(h+delta)，严格复用实际控制器、归一化、BF16 舍入和层位置。额外生成的不同文本不能代替同状态读回。

报告目标激活变化、符号符合率、非目标特征变化、TopK 活跃集合更替、delta/hidden-norm、下一 token 分布 KL，以及答案标记/EOS概率变化。词方向的直接 unembedding 投影只能作诊断；主要依据应是通过后续 transformer 层后的真实 logits。

当前 rho=0.30 尤其需要这项分析：范数匹配并不说明干预只作用于八个特征。基于 SAE decoder 的固定方向注入与激活门控抑制是不同算法，需分开写、分开测。

建议图：强度—目标变化/非目标变化/KL/答案标记概率曲线。

## SAE 分析 D：八个特征是否提供多个独立作用（P0/P1）

计算 decoder 余弦相似度、激活相关性与共激活、八方向矩阵的奇异值和有效秩，以及合成方向与 dense/answer-format 方向的夹角。SAE decoder 一般不是正交基，不能把八个 feature 直接当作八个独立机制。

在固定总扰动范数下比较 top1/top2/top4/top8、八个单特征和 leave-one-out。增加 top16/top32 只使用开发集预先入选且通过同样规则的特征，不为凑数量放宽门槛。先做教师端、只将预先规定的代表条件送入 SFT。

另在发现集估计答案格式子空间，将合成方向在该子空间的投影与正交残差分开。只在残差范数足够时做归一化干预，并登记放大倍数，防止把近零残差噪声放大。这个子空间分解检验可分离性，不是语义纯度认证。

建议图：方向/激活相似矩阵、奇异值谱、固定范数的feature数量—长度/正确率曲线。

## SAE 分析 E：干预发生在什么时候（P1）

从同一32/64-token自然前缀复制独立KV cache，比较正向、零、反向和多个匹配随机方向；前缀不足长的轨迹单独登记。共享随机uniforms减少方差，但不会保证采样分岔后路径相同。

比较固定早期窗口、延迟窗口、全程、答案标记出现后干预。实时策略只能用已生成信息。更强的局部检验是单位置短脉冲并追踪后续变化。报告答案前token、答案后token、关键计算步骤、重复解释、正确率和最终长度。

如果主要变化是答案后赘述，应解释为格式/终止控制；如果答案前有效步骤保留且重复推导减少，才增加对冗余内容假设的支持。反向不必严格对称，报告剂量曲线而非将不对称自动判为失败。

建议图：答案段进入时间分布、答案前后长度分解、同前缀续写案例。

## SAE 分析 F：模型质量与稳定性（P1）

现有六 SAE 已覆盖 layers10/17/23 × k32/64，可先复用，不需立即新增层扫描。主 layer17/k64 留出 explained variance 约0.776、test dead-feature fraction约0.18%；layer10/k32 对应 test dead-feature fraction约53.5%，layer17/k32约36.2%。这些是测试支持上未激活的比例，不能直接断定特征在训练中也死亡。

先检查训练曲线、训练集激活覆盖、重建误差按长度/正确性/位置分层，再判断是否训练不足或存在采样偏差。不要只按 confirmed feature 数量比较 SAE 品质。

主设置增加SAE seeds42/73，保持数据与token预算固定。通过decoder方向和独立集激活模式匹配特征，允许一对多的feature splitting；报告子空间/合成方向稳定性与干预结果，而不是跨seed比较feature ID。

可追加长度预测诊断：文本统计、dense residual线性模型、PCA表示与SAE表示使用相同分组划分和调参预算。预测表现评估增量可读出信息，不等于因果性或教学价值。只对主设置做按轨迹/题目平衡采样对照，避免把long样本的更多token当作更大证据权重。

证据来源：[SAE metrics](../../results/ncsu_phase12_reproduction_v1/exploratory/sae/audit/sae_metrics.csv)。

## SAE 分析 G：连接到学生学习（P1）

用预先定义的正文内容审计，区分计算、解释、验证、重复、答案格式，采用盲于方法的标注和同题比较。词面重复率本身不能等同于数学冗余。

学生NLL可作为低成本诊断：分段计算正文/计算步骤/答案token的NLL，并控制长度；NLL较低不等于训练后泛化更好。最终仍需长度匹配的学生SFT与逐题准确率比较。

利用正在执行的多答案设计分析正确候选文本多样性、解法多样性以及unique-versus-repeat对照。文本去重不是数学解法去重，监督token不匹配的限制保持明确。

当前不自动恢复已暂停的CTV/梯度效用分支，也不把更换学生、跨任务或RL加入当前主矩阵。

## 分阶段执行建议

第一阶段：离线复用现有产物，完成格式区域分解、1/L诊断、方向几何、SAE质量复核；输出是否值得继续语义主张的判断。

第二阶段：在新开发问题上完成目标读回、格式反证、concise/dense/answer-format/多随机教师对照。强度、支持集、选样规则与终点在看结果前登记。

第三阶段：固定主方法及必要对照后，完成三学生seed、两预算SFT。ASC与文本压缩是外部比较的优先补项；主SAE跨seed稳定性与教师因果窗口分析作为补充验证。

建议新增主文图：格式反证矩阵、目标与非目标读回、特征集合剂量曲线、学生准确率—输出长度图。其余质量表与层/seed稳定性放附录。
